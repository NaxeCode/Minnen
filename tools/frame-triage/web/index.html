How a frame becomes a decision

The workbench samples each image at 192 × 112, estimates a translation of up to two sampled pixels, then examines 336 tiles. The trained logistic model scores eight residual, color and context features per tile. The baseline thresholds mean aligned pixel difference. Either method sends a frame to review when any tile crosses its threshold. The overlay uses reference-frame coordinates.

Global camera motion, new art styles, tiny defects and transparent imagery can change the result. The two known failure examples come directly from the held-out set. The Minnen grove uses the game’s Haxe camera with separate illustration code. Each local pair stays in this browser tab.
